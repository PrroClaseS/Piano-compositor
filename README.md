# 🎹 Piano Compositor

**Herramienta gratuita de composición musical para cualquier persona con conocimientos básicos de música.**

Diseñada para estudiantes, músicos, profesores y aficionados. Sin instalación, sin registro, sin costo. Solo abre el archivo en tu navegador y empieza a componer.

---

## ✨ Funcionalidades

- **Compositor** — Piano selector de 5 u 8 octavas con análisis armónico en tiempo real (35+ tipos de acorde). Detecta automáticamente el acorde al seleccionar 3 o más notas y sugiere acordes relacionados por función armónica.
- **Piano Roll** — Editor de notas estilo DAW. Dibuja, mueve, redimensiona, copia, corta y pega notas. Soporte de snap desde semifusa (1/64) hasta redonda (1/1). Zoom, transponer, cuantizar, deshacer/rehacer hasta 50 estados.
- **Partitura en tiempo real** — Grand staff con clave de Sol y Fa. Armadura de clave con 15 tonalidades y 7 modos (Mayor, Menor, Dórico, Frigio, Lidio, Mixolidio, Locrio). Se actualiza automáticamente mientras compones. Exportar como PNG.
- **Reproducción** — Piano Steinway real (Salamander Grand Piano). Loop, metrónomo, control de tempo (BPM) y cabezal arrastrable.

---

## 🚀 Uso

1. Descarga el archivo `index.html`
2. Ábrelo en cualquier navegador moderno (Chrome, Firefox, Edge, Safari)
3. ¡Empieza a componer!

> **Nota:** Se requiere conexión a internet la primera vez por sesión para cargar el audio del piano Salamander.

## 🎹 Atajos de teclado

| Acción | Atajo |
|---|---|
| Dibujar nota | `D` |
| Seleccionar | `S` |
| Borrar | `E` |
| Copiar | `Ctrl + C` |
| Cortar | `Ctrl + X` |
| Pegar | `Ctrl + V` |
| Duplicar | `Ctrl + D` |
| Seleccionar todo | `Ctrl + A` |
| Deshacer | `Ctrl + Z` |
| Rehacer | `Ctrl + Y` |
| Eliminar selección | `Supr` |
| Transponer +semitono | `↑` |
| Transponer -semitono | `↓` |
| Transponer +octava | `Shift + ↑` |
| Transponer -octava | `Shift + ↓` |
| Play / Pausa | `Espacio` |
