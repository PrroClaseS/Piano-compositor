Acerca de Piano Compositor
¿Qué es?

Piano Compositor es una herramienta gratuita de composición musical diseñada para cualquier persona con conocimiento básico de música — estudiantes, músicos, profesores y aficionados. No importa tu nivel ni tu instrumento: si entiendes lo que es una nota, puedes usar este programa para componer, explorar acordes y visualizar tu música en partitura.

Funcionalidades
  • Piano selector de 5 u 8 octavas con detección de acordes en tiempo real (más de 35 tipos)
  • Análisis armónico: acordes mayores, menores, dominantes, disminuidos, aumentados, suspendidos, extensiones hasta la 13ª y alteraciones
  • Sugerencias de acordes relacionados según la tonalidad detectada
  • Gráfico de conexiones armónicas para visualizar progresiones
  • Piano Roll estilo DAW: dibuja, mueve, redimensiona y borra notas con el ratón o dedo
  • Snap ajustable desde semifusa (1/64) hasta redonda (1/1)
  • Reproducción con piano de cola real (Salamander Grand Piano)
  • Partitura en tiempo real con clave de Sol y clave de Fa (grand staff)
  • Selector de tonalidad y modo: Mayor, Menor, Dórico, Frigio, Lidio, Mixolidio, Locrio
  • Armadura de clave automática según la tonalidad seleccionada
  • Soporte para móvil y escritorio
  • 100% gratuito, sin registro, sin publicidad
Instrucciones básicas
  • Compositor: haz clic en las teclas del piano para seleccionar notas y ver el acorde detectado. Usa "Guardar acorde" para construir una progresión.
  • Piano Roll: selecciona la herramienta ✏️ y haz clic en la cuadrícula para crear notas. Arrastra para moverlas, tira del borde derecho para cambiar la duración. Usa ⬚ para seleccionar y ✂ Cortar / ⎘ Copiar / 📋 Pegar.
  • Partitura: se actualiza automáticamente ~3 segundos después de modificar notas en el Roll. Selecciona la tonalidad y modo para mostrar la armadura correcta.
  • Teclas rápidas: D = dibujar · S = seleccionar · E = borrar · Ctrl+C/X/V = copiar/cortar/pegar · Espacio = play/stop · Supr = eliminar selección.
Requisitos técnicos
  • El programa funciona offline desde una USB o carpeta local.
  • El audio (piano real Salamander) requiere conexión a internet la primera vez que se usa en cada sesión.
  • Sin internet, el programa funciona normalmente pero sin sonido.
